Publish checklist
  1. Downloaded test-N.json को chapter folder में रखें, जैसे data/class-10/hindi/dahi-wali-mangamma/test-2.json। Browser Downloads में ही save होता है — folder खुद बनाएँ।
  2. data-<course>-manifest.json को data/<course>/manifest.json पर replace करें।
  3. data-manifest.json को data/manifest.json पर replace करें।
  4. Git commit और push करें; GitHub Pages update होने दें।
Browser security के कारण यह page repo files सीधे overwrite नहीं कर सकता। दोनों manifests के नाम अलग रखे गए हैं ताकि Downloads में टकराव न हो।
